# P2.4: Retention/Archival — Capability Audit

## Status

Audit phase — 2026-09-08

## Boundary Decision

**Retention primitives can belong to MagicORM. Retention policy belongs to the application.**

```
MagicORM                          Application (Thalos)
─────────────────────────────     ─────────────────────────────
DELETE with WHERE                 "delete records older than 30 days"
Bulk deletion                     Scheduling retention jobs
Temporal filters                  Archival destination (Parquet, S3, etc.)
Transactions                      Compression
Streaming for export              Retention policy configuration
COUNT for volume check            Monitoring retention effectiveness
```

## Existing Primitives Audit

### 1. Bulk DELETE

**Status:** ❌ Not implemented as a dedicated method.

**Current capability:**
```rust
// Via execute() — returns rows affected
let affected = Observation::query()
    .filter("timestamp", "<", cutoff)
    .execute(&pool)
    .await?;
```

**Works but:**
- No `delete()` method on QueryBuilder
- Requires `.execute()` which is semantically UPDATE/DELETE
- No batched deletion for large datasets

### 2. Temporal Filters

**Status:** ✅ Complete

```rust
.filter("timestamp", ">=", start)
.filter("timestamp", "<", end)
.filter_null("deleted_at")
.filter_not_null("archived_at")
```

### 3. Transactions

**Status:** ✅ Complete

```rust
let mut tx = pool.begin().await?;
// deletion inside transaction
tx.commit().await?;
```

### 4. Batch Operations

**Status:** ✅ Complete (`insert_many`)

**Gap:** No `delete_many` for batch deletion.

### 5. COUNT

**Status:** ✅ Complete

```rust
let count = Observation::query()
    .filter("timestamp", "<", cutoff)
    .count()
    .fetch_count(&pool)
    .await?;
```

### 6. Streaming

**Status:** ✅ Complete

```rust
let mut stream = Observation::query()
    .filter("timestamp", "<", cutoff)
    .stream(&pool)?;
```

### 7. SQLite-specific Capabilities

## What's Missing for Retention

### Priority 1: Bulk DELETE method

```rust
// Proposed API
let deleted = Observation::query()
    .filter("timestamp", "<", cutoff)
    .delete(&pool)
    .await?;
```

### Priority 2: VACUUM after large deletion

```rust
// After deleting old records
Observation::query()
    .filter("timestamp", "<", cutoff)
    .delete(&pool)
    .await?;

// Reclaim space
sqlx::query("VACUUM").execute(&pool).await?;
```

### Priority 3: Database size check

```rust
// Before retention job
let size = Sqlite::database_size(&pool).await?;
if size > threshold {
    // run retention
}
```

## What Does NOT Belong in MagicORM

- Retention scheduling (cron, intervals)
- Archival destination (Parquet, S3, PostgreSQL)
- Compression
- Retention policy configuration
- Monitoring/alerting

## Proposed P2.4 Scope

1. Add `delete()` method to QueryBuilder
2. Add `VACUUM` helper (optional, SQLite-specific)
3. Add `database_size()` helper (optional, SQLite-specific)
4. Document retention patterns
5. Benchmark large deletion + VACUUM
